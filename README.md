Smart Spoon

Smart Spoon is a web-based prototype for an AI-powered device designed to enhance salty and umami tastes using safe electric stimulation. Tailored for individuals on low-sodium diets (e.g., those with hypertension or kidney disease), it uses machine learning to adjust taste intensity based on user preferences, food type, and health conditions. The companion web app allows users to input food choices, dietary restrictions, and taste preferences, providing personalized taste settings and accepting feedback to refine recommendations.

Note: This is a software prototype. Real-world functionality requires integration with a physical Smart Spoon device equipped with sensors and hardware for taste stimulation.

Features





Food Selection: Choose from a variety of foods (e.g., Curry, Pizza, Soup) to receive taste enhancement settings.



User Profile: Input age, dietary restrictions (e.g., Hypertension, Kidney Disease), and preferences for saltiness and umami (1–5 scale).



Taste Prediction: AI-driven recommendations for taste intensity based on food texture, health conditions, and user preferences.



Feedback System: Submit feedback in the format "Disease Intensity" (e.g., "Hypertension 3.5") to refine taste models, with strict validation to ensure correct input.



Educational Sidebar: Learn about salt vs. sodium, umami, health risks of high sodium, and tips for low-sodium Indian diets.
